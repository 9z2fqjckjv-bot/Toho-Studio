# Google Cloud 40ドル予算でのLLM対応Linux仮想環境構築ガイド

1ヶ月あたり40ドル（約6,000円前後）の予算内で、Google Cloud（Compute Engine）上でLLMを動かすLinux仮想環境を構築するための構成案、コスト試算、および安定運用・割引に関するまとめです。

---

## 1\. 推奨される構成パターン（パターンA：軽量LLM特化）

CPU上でLlama 3 (8B) の量子化モデルや、Phi-3、Qwen 2.5 (1.5B〜7B) などの軽量LLMをローカル動作させる構成です。

### スペック構成案

* **インスタンスタイプ**: `e2-medium` (共有 vCPU 2基 / メモリ 4 GB)  
* **OSイメージ**: Ubuntu 22.04 LTS または Debian 12  
* **ストレージ（永続ディスク）**: 標準永続ディスク **50 GB**（モデルファイルやDockerイメージ用）  
* **リージョン**: `us-central1`（米国中西部：GCPで最も単価が安いため）または `asia-northeast1`（東京：速度重視）

### 月額コストの内訳（目安）

米国リージョンで24時間30日（730時間）常時稼働させた場合のシミュレーション：

| 項目 | スペック・容量 | 月額コスト（目安） |
| :---- | :---- | :---- |
| **仮想マシン** (`e2-medium`) | 2 vCPU / 4GB メモリ | 約 **\$24.46** |
| **ストレージ** | 標準永続ディスク 50GB | 約 **\$2.00 〜 \$2.50** |
| **ネットワーク** | 外部データ転送（小規模） | 約 **\$1.00 〜 \$2.00** |
| **合計** |  | **約 \$28 〜 \$30 /月** |

※ 40ドルの予算内に余裕（約10ドル分）を持たせることができます。

### ソフトウェア構成と動かせるモデル

* **主要ツール**: `Ollama`（バックエンドの推論） \+ `Open WebUI`（ChatGPT風ブラウザ画面、Dockerで構築）  
* **動かせる軽量モデル**:  
  * Qwen 2.5 (1.5B / 3B の量子化モデル)  
  * Phi-3.5 mini (3.8B) 等  
* **CPU推論のパフォーマンス**: 生成速度は概ね「1秒あたり数文字〜10数文字程度」となります。

## 2\. 安定した常時運用を目指すためのポイント

予期せぬトラブルを防ぎ、24時間365日安定して稼働させるためのアプローチです。

1. **オンデマンドインスタンスの利用**  
   * スポット（プリエンプティブル）ではなく通常のオンデマンドインスタンスとすることで、突然の強制終了リスクを排除します。  
2. **自動再起動（Auto-restart）の設定**  
   * GCP側の可用性ポリシーでホストメンテナンス時は「インスタンスを移行する（Migrate instance）」に設定。  
   * Dockerコンテナには `restart: always`（または `unless-stopped`）を記述し、万が一の再起動時も自動復旧するように設定します。  
3. **スワップ領域（Swap）の確保**  
   * メモリ4GB環境でのメモリ枯渇（OOM Killerによる強制終了）を防ぐため、Linux側に2GB〜4GBのスワップ領域を設定します。

## 3\. 確約利用割引（CUD）と支払いタイミングについて

長期運用を行う場合に利用できる割引制度の仕組みです。

* **支払いのタイミング**:  
  * AWSのReserved Instanceのような\*\*「一括の前払い（前払いオプション）」はありません。\*\*  
  * 1年または3年の契約期間中、**毎月の請求締めに合わせて月単位で後払い**する仕組みです。  
* **特徴**:  
  * まとまった初期費用が不要で、通常のクラウド利用料金と同じ感覚で分割して支払うことができます。  
  * コミットしたリソースに対して毎月料金が発生するため、実際に使った量に関わらず一定額が請求されます。  
  * 安定運用に慣れた後、より上位のスペック（`e2-standard-2` など）へ移行する際のコスト調整に活用できます。
