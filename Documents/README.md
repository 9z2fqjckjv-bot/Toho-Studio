Toho-Studio は、東方Projectの二次創作活動を総合的に支援するために開発された、macOS ネイティブの統合クリエイティブスイートです。  
動画編集、キャラクター立ち絵編集、AquesTalkによるゆっくり音声合成、スライド＆シナリオ制作、横長ワイド東方RPG制作、共通素材データベースを一元化しています。

---

## 🌟 6つの内蔵ソフト (Built-in Suites)

1. **ムービーメーカー (MovieMaker)** - *ベース: GoogleVids*
   - タイムライン上でのシーン編集、テロップ、スライド読み込み、YMMP4互換
   - プレビュー再生、全画面再生 (cmd+p+a)、倍速再生、デバッグ再生 (cmd+p+shift+d)
   - MP4, MOV, YMMP, GVID, FCPBUNDLE, PRPROJ 書き出し対応
   - FinalCutPro / Premiere Pro 非搭載機能アプリ拡張対応

2. **キャラクターメーカー (CharacterMaker)** - *ベース: Google図形描画*
   - 立ち絵のパーツ分割（顔、目、口、体、髪、装飾）と自由な組み立て
   - 表情差分切り替え（通常、笑顔、怒り、驚き、困惑）
   - PNG透過立ち絵、JPG、SVG、PSD、PXD、GDRAW 出力対応
   - Photoshop / Pixelmator Pro 非搭載機能アプリ拡張対応

3. **サウンドメーカー (SoundMaker)** - *AquesTalk ゆっくりボイス & BGM/SE ミキサー*
   - AquesTalk1 (ゆっくりボイス) & AqKanji2Koe 漢字記号変換エンジン直結
   - スライド＆シナリオのセリフ文から()書き表記（アニメーション・時間指定・演出）を完全除去したクリーンな音声一括生成・個別生成
   - 声種切替 (女声1/2/3, 男声1/2, ロボット, 中性, 児童)、発話速度・音量調整、高音質化・エコー処理
   - BGM / SE クリップのミキシング・音量バランス調整
   - WAV, MP3, M4A, AAC, AIFF, LOGICX, SESX 書き出し対応

4. **スライド＆シナリオメーカー (SlideScenarioMaker)** - *Googleスライド / Keynote 互換*
   - スライド編集と台本シナリオ（発表者ノート連動、セリフ文の後の()書きアニメーション表記UI自動除去・保持）
   - **高精度スライド認識プログラム (精度99%規格)**: Keynoteスライドからオブジェクト・背景画像・キャラクター（動画用素材フォルダ自動照合）・アニメーション・テロップを7ステップで自動解析・紐付け
   - スライド3種分離（背景/立ち絵/テロップ）およびシナリオ文節分解

5. **ゲームメーカー (GameMaker)** - *横長ワイド東方RPG / ノベルゲーム制作*
   - スライド＋台本シナリオ＋AquesTalk音声を読み込み、横長ワイド画面の本格ゲームを構築
   - シナリオ上へのコマンド記述（選択肢、分岐、プレイヤーHP/所持金設定、マルチエンディング）
   - 全画面テストプレイ環境 (cmd+d+a) 搭載

6. **素材スタジオ (MaterialStudio)** - *基幹・中枢ストレージ*
   - 全内蔵ソフトの画像・音声・スライド・シナリオ・ゲームプロジェクトを一元管理
   - ローカル、Googleドライブ (`マイドライブ/Toho-Studio`)、NanndemoyaCloud 保存先切替
   - スライド抽出フィルター（立ち絵/アニメーション/トランジション/背景）
   - 単語フィルター（YouTube, ニコニコ動画, Steam, Roblox, Epic Games ポリシー照合＆安全な単語への置換）
   - AI高度検索・置換（プロンプトによる画像生成・音声合成・テキスト置換）
   - ローカル無償セキュリティ点検（ウイルス・マルウェア検知スキャナ）

### 起動方法
1. `Application/Toho-Studio.app` をダブルクリックして起動します。
2. 初回起動時はアプリケーションツアーと規約同意・アカウント設定ウィザードが表示されます。
3. AquesTalkの商用ライセンスキーをお持ちの場合は、設定画面の「ライセンスと認証設定」よりご自身のキーを入力してご利用ください（未設定時はデモ・フォールバックモードで安全に動作します）。
