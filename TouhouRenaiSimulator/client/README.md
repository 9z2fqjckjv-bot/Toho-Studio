# 東方Project恋愛シミュレーター（クライアント版）

Mac / Linux / Windows 対応のデスクトップクライアントです。

## 特徴・ライセンスおよびセキュリティ設計

- **外部素材の非同梱・サーバー非配信（利用者PCローカル参照方式）**:
  立ち絵（`はるか式立ち絵` 等）および背景素材（ニコニ・コモンズ等）の再配布・商用配信防止のため、本クライアントにもホストサーバーにも外部画像素材は同梱・配信されません。利用者ご自身が各配布元から取得しPCのローカルフォルダに配置した画像を、クライアントが直接読み込んで表示します。
- **AquesTalk1 ライブラリ非同梱**:
  本クライアントには株式会社アクエスト製 `AquesTalk1` の共有ライブラリ（`.so` / `.dll` 等）および辞書データは一切含まれていません。
- **秘密鍵・APIキー非同梱**:
  サーバー接続用の秘密鍵やOAuthシークレットは一切埋め込まれていません。「GeminiAPIキーで指定」モードを選択した場合も、入力したキーは利用者ご自身のPC内（`~/.touhou_renai_simulator/local_config.json`）にのみ権限 `600` で保存されます。
- **1会話1ローカルセーブ**:
  会話が1ターン進むごとに、会話テキスト・好感度・初期設定・セリフ音声（`.wav`）が `~/.touhou_renai_simulator/saves/` に自動保存されます。

## 事前準備：外部素材（立ち絵・背景）の配置方法

1. 初回起動時に `~/.touhou_renai_simulator/assets/` 内に `はるか式立ち絵` フォルダと `背景` フォルダが自動作成されます（起動画面の「**フォルダを開く**」ボタンからすぐ開けます）。
2. ご自身でダウンロードした立ち絵PNG群・背景画像群を配置するか、起動画面の「**ローカル素材フォルダ設定 → 参照…**」から既存の素材フォルダを指定してください。

## 起動方法

- **macOS**: `東方Project恋愛シミュレーター.command` をダブルクリック（または `python3 renai_client.py`）
- **Linux**: `東方Project恋愛シミュレーター.sh` または `.desktop` を起動
- **Windows**: `東方Project恋愛シミュレーター.bat` をダブルクリック（Python 3 標準ライブラリのみで動作）

## 操作方法

- **キャラクター・性別選択画面**:
  - `←` / `→` キー: 出演作品・分類の切替
  - `↑` / `↓` キー: キャラクターの切替
  - `M` キー / `W` キー: 主人公の性別切替（男 / 女）
- **会話画面**:
  - メッセージ枠クリック または `Enter` / `Space` キー: セリフ進行・選択肢表示
