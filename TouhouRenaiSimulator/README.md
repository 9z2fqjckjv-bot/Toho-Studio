# 🌸 東方Project恋愛シミュレーター ＆ キャラステージ演出メーカー (Standalone Edition)

本ディレクトリ (`TouhouRenaiSimulator/`) は、`Toho-Studio` リポジトリ内の既存プログラム（`Application/`, `New/`, `DMG&ZIP/` 等）と一切干渉せず独立して動作する **超省メモリ・省CPU設計の恋愛シミュレーター ＆ 立ち絵・ステージ演出統合スイート** です。

## 🚀 ダウンロードしてすぐ遊ぶ方法（インストール作業不要）

**Python 3（macOS / Linux 標準搭載、Windows は python.org 版）** のみで、`pip install` なしですぐに起動できます。

1. 単体ZIP（[`packages/TouhouRenaiSimulator-ReadyToRun-AllOS.zip`](./packages/TouhouRenaiSimulator-ReadyToRun-AllOS.zip)）または本フォルダをダウンロードします。
2. お使いのOSに合わせて以下をダブルクリック（または実行）します：
   - **macOS**: `起動_Mac.command`
   - **Linux**: `起動_Linux.sh`
   - **Windows**: `起動_Windows.bat`
3. 起動画面で **「⚡ APIキー・単体モードで始める」** を押し、ご自身の **Gemini API キー** を入力すると（空欄のオフラインデモ動作も可）、すぐに対話を開始できます。

## ✨ 主な搭載機能

1. **プレゼンソフト風キャラクター拡大縮小・18種モーション・効果音再生 (`stage_director`)**
   - 地の文 → セリフの2段階で立ち絵の距離感（遠景72% 〜 急接近138% 〜 抱擁156%アップ）と背景ボケをGPU合成で滑らかに補間。
   - Web Audioリアルタイム合成による **内蔵効果音20種（メモリ0KB）** を標準搭載。さらにローカルの `効果音` フォルダに `.wav`/`.mp3`/`.ogg` を置くと自動認識します。
   - `ステージ演出メーカー_Mac.command` / `_Linux.sh` / `_Windows.bat` から単体のプレゼン演出スタジオとしても起動・編集可能です。
2. **『東方キャラ立絵スタジオ』内蔵（立ち絵作成・パーツ組替・色変え・スポイト特定色置換）**
   - ゲーム画面上部の **「👗 立ち絵・色変え」**（またはキャラ選択画面の **「🌸 立ち絵スタジオ・色変え」**）から、PSDの目・口・眉・漫符組替、部位別色変え、雰囲気フィルター10種、陰影を保ったスポイト特定色置換、および全表情プリセット一括ゲーム反映が可能です。
3. **会話内容に忠実な背景自動選択 ＆ AI新規背景生成**
   - 全ローカル背景から会話場面に最も合う背景をAIが選択し、該当する背景がない場面では会話描写に忠実な16:9背景を Gemini 画像生成モデル（`gemini-nano-banana-2.1` 等）で自動生成します。
4. **APIキー利用時限定の自由会話入力 ＆ 会話連動の動的性格シフト**
   - Gemini APIキーを設定して利用している場合のみ、3択に加えて自由な言葉でヒロインに話しかけることができます。
   - 会話の接し方に応じて全50種の性格属性が毎ターン自然に変化するほか、手動での性格固定・ハイブリッド設定にも対応しています。
5. **セーブデータの読み込み・巻き戻し・分岐・ZIP書出/読込**
   - 全セーブ一覧からのロード、任意の過去ターンからの巻き戻し・別セーブ分岐再開、外部 `.zip` / `.json` セーブのインポートに対応しています。

## 📁 任意のローカル素材（立ち絵・背景・効果音）を使う場合

本パッケージには初期状態で動作確認できるベクター立ち絵・背景・内蔵シンセ効果音が同梱されていますが、ご自身のPCにダウンロード済みの **「はるか式立ち絵」（PNG / PSD）** や **「背景」**、**「効果音」** フォルダを起動画面の **「📁 ローカル素材フォルダ設定」** で指定すると、そのまま高精細立ち絵・PSDレイヤー編集が有効になります。

## 🔒 ライセンス・クリーン配布について

本リポジトリ配布パッケージには、各種APIキー・認証シークレット・(株)アクエスト社の AquesTalk ライブラリ本体（`.so`/`.dll`/`.dylib`/`.phont`/辞書）・ライセンスキー・第三者画像素材は一切含まれていません。
