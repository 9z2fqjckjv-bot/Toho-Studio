# 🎬 キャラステージ演出メーカー (Presentation-Style Stage & SFX Director)

『東方Project恋愛シミュレーター』の Gemini API から直接呼び出せる **超省メモリ・省CPU設計のプレゼンテーション風キャラクター演出＆効果音スタジオ** です。

## 🌿 超省リソース設計
- **常駐デーモンなし・待機時メモリ 0MB / CPU 0%**:
  - 恋愛シミュレーター稼働時は、`server/gemini_service.py` が `stage_director_engine.py`（Python標準ライブラリのみ）を同一プロセス内で直接呼び出すため、**追加プロセス0個・追加メモリ約0.2MB未満**で動作します。
  - 単体スタジオ起動時も `nice -n 15` で動作し、ウィンドウを閉じると約25秒後にサーバーが自動終了してメモリを完全解放します。
- **GPUコンポジタ専用アニメーション ＆ 有限回数再生**:
  - Keynote / PowerPoint のマジックムーブのように `translate3d` + `scale` のみで補間し、全18種のモーションは有限回数で完了して静止状態に戻るため、**アイドル時のブラウザCPU占有率は 0.0%** です。
- **メモリ0KBの内蔵プロシージャル効果音（20種）＋ ローカル効果音フォルダ自動認識**:
  - Web Audio API によるリアルタイム合成SE 20種（足音・駆け寄り・衣擦れ・ハグ・鼓動・早鐘・きらめき・赤面・疑問・驚き・怒り・ツッコミ・ヤンデレ低音・吐息・ノック・扉・お茶・そよ風・魔法・ウェディングベル）を標準搭載。
  - `~/Documents/効果音` または `~/.touhou_renai_simulator/assets/効果音` に `.wav` / `.mp3` / `.ogg` を配置すると自動認識し、Gemini API が優先呼び出しします。

## 🚀 単体スタジオ起動方法
- デスクトップまたは本フォルダ内の **`キャラステージ演出メーカー.desktop`** / **`キャラステージ演出メーカー.sh`** を起動
- 恋愛シミュレーターのセーブデータ（`~/.touhou_renai_simulator/saves`）をスライド一覧として読み込み、拡大率・モーション・効果音を確認・編集してそのままセーブへ上書き保存できます。
