# Linux認証プログラムの利用方法  
```
ヘルプトップ＞ガイド＞アカウント＞ローカルアカウント＞Linux認証プログラムの利用方法

```
Linux認証プログラムの利用方法をこの記事では紹介しています。  
  
## Linux認証プログラムが必要になるとき…  
  
Linux認証プログラムが必要になるときは、ローカルアカウントで予備の認証方法を設定する場合に、通話認証やSMS認証が選べない場合における認証方法です。  
このプログラムでは、あなたのアプリーケーションに紐づいているローカルアカウント情報を仮想Linux環境に流し込むことで、アプリケーションの認証と仮想Linuxでの同時認証が実行され、よりローカルアカウントのセキュリティーが強化され、安全に利用できるようになります。  
初回の起動時には、メール認証時にお送りした確認及び認証コード通知に、記載されたUserIDとLinux認証プログラム利用時の初期パスワードを利用し、ログインします。  
また、初回ログインが正常に記録されると、こちら側で作成した仮想Linux上のローカルアカウント情報が表示され、承認をすることで、次回からは、初回ログイン時に書き換えた新しいパスワードとメールに記載のUserID（こちらは変更できません。）を入力することで、情報が読み込まれ、認証できるようになります。  
  
## 困ったときは…  
  
以下には、Linux認証プログラムで困った場合の主な対処法を載せています。詳細は、Q&Aのリンクから見れます。  
  
### 初回メール認証時の確認メールを誤って破棄し、UserIDと初期パスワードを紛失した場合  
  
この場合は、再度、最初の手順からローカルアカウントを再作成申請をしてください。  
  
### UserIDの忘れた場合  
  
UserIDを忘れた場合は、SecurityToolsのローカルアカウント情報から氏名とともに確認できます。  
  
### 自分で設定したパスワードやセキュリティー設定内容（秘密の質問など）を忘れた場合  
  
パスワードを紛失した場合は、Linux認証プログラム起動時に表示されるアカウント復旧プロセスから、アカウントの復元を試みてください。  
もし、それでもアカウントを復元できない場合、開発者宛に[Linux認証情報の開示請求申請](https://docs.google.com/forms/d/e/1FAIpQLSdB4qtfXMY1BVqShVcMQjnZydMxx2zVK1Cnfrj1nLreHk0LcQ/viewform?usp=publish-editor)をしてください。
