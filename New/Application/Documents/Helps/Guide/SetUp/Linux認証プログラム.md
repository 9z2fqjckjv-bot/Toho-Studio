# Linux認証プログラム  
```
ヘルプトップ＞ガイド＞セットアップ＞Linux認証プログラム

```
  
ローカルアカウントの作成時に、予備の認証方法を設定するための手段として、Linux認証があります。  
Linux認証は、仮想環境上にあるLinuxにあなたのローカルアカウントを作成し、アプリケーションからそのアカウントにアクセスし、指定されたパスにある認証プログラムを実行することで認証する方法です。  
この方法の場合、アプリケーションが起動するたびに認証プロセスがバックグラウンドで走るため、お使いの仮想Mac環境によっては、アプリケーションのパフォーマンスに悪影響を与える場合があります。  
その場合は、開発者に問い合わせ、対処方法をお尋ねください。  
以下にプログラムの詳細を記載します。  
  
## プログラム名称  
  
Linux認証プログラム（ファイル名称は、Local_Security_Linux）  
  
## 概要  
  
アプリケーション上のローカルアカウント利用者の連絡先情報と利用情報を、仮想Linux上に送信し、Linux上での情報の差異がないかの確認及び、仮パスワードの発行と認証チェックに利用される。  
  
## 目的  
  
アプリケーション上のローカルアカウントを開く際に、ログインが必要であり、その際に必要なパスワード紛失時や、メール連絡が不通となった場合に備えた認証方法として活用し、２段階認証時にも利用する。  
また、本人確認などの情報もプログラムを活用し管理する目的がある。  
  
## 注意事項  
  
本プログラムを用いて、認証をする場合、場合によっては、認証完了までに待機時間が発生することがある。また、初回認証時には、開発者側で認証を手動実行し、プログラムの追加までを行うため、数時間から数日程度の待機時間が必要。  
また、原則として、このプログラムを利用する場合は、仮想Linux上の利用者のアカウントが認証機能に特化した構成になるため、有料機能やLinuxとの通信が前提となる機能の利用ができなくなる。  
これらの機能を利用したい場合は、別の予備の認証方法をセットアップするか、NanndemoyaCloud、Googleアカウントでのログインと認証を選ばなければならない。
