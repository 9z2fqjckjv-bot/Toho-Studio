# セリフ生成方法の固定  
```
ヘルプトップ＞ガイド＞サウンドメーカー＞オプション＞サウンドメーカーのデフォルトオプション＞セリフ生成方法の固定

```
サウンドメーカーのオプション画面における「セリフ生成方法の固定」機能を活用することで、以下のような明確かつ具体的な利点を享受することが可能です。  
  
1. ****音声記号列のカスタマイズ固定****  
    * カスタマイズをオフに設定することで、あらかじめ定められた変換ルールに基づきセリフが自動生成されます。  
    * 既存のカスタマイズ設定は保持されるため、従来の作業環境を損なうことなく運用可能です。  
2. ****辞書機能の学習設定固定****  
    * 学習設定をオフにすることで、不要な学習を防止し、既定の辞書に基づく正確な読み上げを適用できます。  
3. ****音声合成エンジンの固定****  
    * エンジンを固定することにより、誤ったエンジンでの変換や音声誤生成のリスクを低減します。  
4. ****音量調整の固定****  
    * 音量調整をオンに固定すると、セリフ音声・BGM・効果音・楽譜再生時の音量が自動で均衡され、一定の音量で安定した出力が実現します。  
5. ****効果音割当方式の固定****  
    * 効果音を時間式に固定することで、セリフ本文が変更されても、同一タイミングでの効果音再生を保持できます。  
6. **BGM設定の固定**  
    * BGMをなしに設定することで、ソフトウェア側の自動挿入を防止します。  
    * BGMをありにすると、意図しない場面で自動挿入される可能性があります。  
7. ****新規収録機能のオフ設定****  
    * 新規収録をオフにすることで、編集画面がよりスタイリッシュかつシンプルになり、誤操作による楽器音の割り込みを防止します。  
    * さらに、新規収録用のプログラムやデータが削除されるため、ソフトウェアのストレージ使用量削減にも寄与します。  
*   
以上の設定は、お客様の利用目的や作業フローに応じて最適化することが推奨されます。詳細は以下の資料をご参照ください。
