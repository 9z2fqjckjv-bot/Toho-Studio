概要

アプリケーション起動不能問題の完全修復、/Applications 配下のアプリへの最新変更反映、および TohoAIStudio V3.0・外部API永続化改善を含む v2.9.3 最新リソース。

  • アプリケーション起動不能問題の修正とバンドル整合性復旧：欠損していたリリース実行バイナリ（Contents/MacOS/TohoStudio および Toho-Studio）の再ビルド・再配置、Info.plist の NSAppTransportSecurity（ローカル・ゲートウェイ通信許可）反映、Ad-hoc コード署名（codesign --deep）および LaunchServices 再登録、さらに /Applications/Toho-Studio.app への最新バイナリ・リソース完全同期
  • TohoAIStudio V3.0 パブリックゲートウェイ＆新料金プラン移行対応：パブリックゲートウェイサーバー（gateway_server.py）・管理CLI（admin_cli.py）・MacMiniデプロイスクリプト（deploy_macmini.sh）統合、原価ベースの料金プラン改定（pricing_plans.py）および旧プランからの自動マイグレーション実装
  • 外部AI API連携の永続化・モデル自動検出・定額枠分離：プロバイダ選択・モデル選択・外部APIキー設定（Nanndemoya / Gemini / ChatGPT / Claude / Grok）の UserDefaults 永続化、Gemini / Claude 最新モデル候補の自動検出・フォールバック（x-goog-api-key ヘッダー対応）、外部API管理画面からのワンクリックAIチャット切替、および外部API利用時の定額プロンプト枠消費除外（AIEditor / AIImageGenerator）
  • クラウド仮想Linux監視の強化：起動時ヘルスチェック即時実行、リアルタイムCPU使用率・メモリ使用率テレメトリ同期、プロンプト残数ゼロ一時停止状態の保持改善
  • アプリケーション各画面（Info.plist, AppTopScreenView, AppInfoView, DeveloperConsoleView, MenuBarModals, RootView, MovieExporter, AppState）におけるバージョン表記の v2.9.3 統一、および最新リソース整合性マニフェスト（integrity_manifest.json）の更新
  • 新規配布パッケージ（v2.9.3.dmg / v2.9.3.zip / v2.9.dmg / v2.9.zip）の生成・GitHubリリース（リソースページ）公開
