# クラウド保存

クラウド保存をすると、NanndemoyaCloudのアカウント上のGoogleドライブに以下のようなフォルダ構成が自動作成され、保存可能ファイルを保存できます。

* マイドライブ  
  * Toho-Studio  
    * Cloud-Saving  
      * SoftWare  
        * Movie  
          * ムービーメーカーの編集ファイル（.tsvm）  
        * Sound  
          * サウンドメーカーの編集ファイル（.tssm）  
        * Character  
          * キャラクターメーカーの編集ファイル（.tscm）  
        * Slides\&Scenario  
          * スライド＆シナリオメーカーの編集ファイル（.tspm）  
        * GameMarker  
          * ゲームメーカーの編集ファイル（.tsgm）  
        * MaterialStudio  
          * 素材スタジオの全てのファイル
