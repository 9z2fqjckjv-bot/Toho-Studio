# データ移行

クラウド保存で作成した以下のフォルダ構成のデータをGoogleアカウントに移行します。

* マイドライブ  
  * Toho-Studio  
    * Cloud-Saving  
      * SoftWare  
        * Movie  
          * ムービーメーカーの編集ファイル（.tsvm）  
        * Sound  
          * サウンドメーカーの編集ファイル（.tssm）  
        * Character  
          * キャラクターメーカーの編集ファイル（.tscm）  
        * Slides\&Scenario  
          * スライド＆シナリオメーカーの編集ファイル（.tspm）  
        * GameMarker  
          * ゲームメーカーの編集ファイル（.tsgm）  
        * MaterialStudio  
          * 素材スタジオの全てのファイル
